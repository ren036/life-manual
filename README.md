# 生活手册

一个面向个人、优先适配手机的生活 PWA：随手记下，需要时找得到。

## 界面结构

- **今天**：快速随记、保存资料、添加待办；查看今日事项、资料到期提醒与最近打开的记录。
- **记录**：统一收纳资料、随记和菜谱，支持跨类型搜索；资料与随记使用阅读列表，菜谱保留照片视图和买菜清单。
- **待办**：集中查看和处理日常事项，支持关联资料、重复提醒和完成状态。
- **我的**：外观、分类整理、备份恢复与回收站。个人使用，无需注册账号。

手机使用四项底部导航，桌面使用侧栏；整套界面采用统一灰蓝色调、文字层级和分隔线。旧记录和附件沿用原有存储，无需迁移。

## 主要功能

- 用图片卡片记录做过的菜，可填写食材、分类和心得
- 为每道菜保存多次下厨记录，支持只写心得，也可附照片，并可编辑、删除或撤销删除
- 保存图片、PDF、Word 等资料，可分类并标记重要
- 选择或拍摄照片后直接批量添加，按需点击缩略图上的裁剪按钮；编辑记录时也可再次裁剪
- 使用手机拍照扫描资料，在设备上识别中文文字并参与搜索
- 创建带分类、截止日期和优先级的待办事项
- 将待办关联到菜谱或资料，并从记录详情快速创建提醒
- 使用统一分类，并可批量修改分类或追加标签
- 完成或恢复待办，分别查看进行中与已完成事项
- 自动兼容并整理旧版生活记录
- 手机编辑窗口固定显示保存按钮，更多设置默认收起
- 新增和编辑时自动保留本机草稿（含已添加附件），重新打开可继续，正式保存后清除草稿
- 顶部搜索入口搜索所有记录；待办保留独立搜索
- 保存资料或菜谱后直接打开详情，资料创建到期提醒时预填名称、日期和关联
- 随记只写正文即可保存，标题和心情默认收起
- 搜索、分类、排序与阅读位置在页面切换后保留；分类和标签可在筛选面板中查找
- 随记拥有独立阅读页，待办支持列表搜索和更易点击的操作菜单
- 数据保存在当前设备
- 支持离线访问和 iPhone 主屏幕安装

## 技术栈

- Vite
- React
- React Router（HashRouter）
- TypeScript
- PWA Service Worker
- IndexedDB：菜谱、资料、待办和附件

## 项目结构

```text
life-manual/
├─ public/                 # PWA 清单和离线缓存脚本
├─ src/
│  ├─ components/         # 通用界面组件
│  ├─ hooks/              # 记录、待办、提醒和数据管理逻辑
│  ├─ pages/              # 今天、统一记录库、待办、我的和详情页面
│  ├─ storage/            # 本地记录与附件存储
│  ├─ attachments.ts      # 附件与菜谱封面工具
│  ├─ dueDates.ts         # 日期计算与到期状态
│  ├─ library.ts          # 跨类型记录搜索与展示
│  ├─ App.tsx             # 路由和界面组装
│  ├─ main.tsx            # React 启动文件
│  ├─ styles.css          # 全局样式
│  ├─ redesign.css        # 个人版布局与视觉系统
│  └─ types.ts            # TypeScript 类型
├─ index.html
├─ package.json
├─ tsconfig.json
└─ vite.config.ts
```

## 本地开发

需要安装 Node.js 18 或更高版本。

```powershell
cd D:\life-manual
npm install
npm run dev
```

默认开发地址为 `http://localhost:5174/`；如果端口已被占用，Vite 会直接提示，以免悄悄换到其他端口。

## 生产构建

```powershell
npm run build
```

构建结果位于 `dist` 文件夹。

## 页面地址

页面使用哈希路由：`#/`、`#/records`、`#/tasks` 和 `#/profile`。资料、菜谱与随记详情仍使用 `#/documents/记录ID`、`#/recipes/记录ID` 和 `#/notes/记录ID`。旧列表链接会转到记录库对应类型，旧版 `#recipes/记录ID` 链接也会自动转换。

## 在 iPhone 上安装

PWA 需要通过 HTTPS 地址访问后才能稳定安装到手机。部署完成后：

1. 使用 iPhone 的 Safari 打开应用地址。
2. 点击 Safari 底部的“分享”按钮。
3. 选择“添加到主屏幕”。
4. 点击“添加”。

之后可以像普通 App 一样从 iPhone 桌面打开。

## 数据说明

当前版本采用本地优先设计：

- 文字记录、图片和文件统一保存在浏览器 IndexedDB。
- 不需要注册账号，也不会自动上传个人内容。
- 清除 Safari 网站数据会同时删除本地记录，请勿将当前版本作为重要文件的唯一备份。

在「我的」中可导出包含附件的完整备份并恢复；当前不自动同步到 iCloud。
